## Historia
Como usuario quiero crear una solicitud con título y descripción para registrar una petición.

## Criterios de aceptación (borrador)
- `POST /requests` con `title` y `description` crea la solicitud y devuelve 201 con `id`, `title`, `description`, `status: "open"` y `created_at`.
- Si falta `title` o está vacío, devuelve 400 con un mensaje de error.
- `title` tiene un máximo de 100 caracteres; si se supera, devuelve 400.

## Notas
- Las solicitudes se guardan en memoria.
- Pendiente de decidir: ¿`description` es obligatoria? ¿Qué pasa con un título que solo tiene espacios?
