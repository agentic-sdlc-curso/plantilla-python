## Historia
Como responsable quiero cambiar el estado de una solicitud para reflejar en qué punto está.

## Criterios de aceptación (borrador)
- `PATCH /requests/{id}/status` con `{ "status": "<nuevo estado>" }` cambia el estado y devuelve 200 con la solicitud actualizada.
- Transiciones permitidas: `open → in_progress` e `in_progress → closed`.
- Cualquier otra transición devuelve 409. Una solicitud cerrada no se puede reabrir.
- Un estado que no existe devuelve 400.
- Si el id no existe, devuelve 404.
