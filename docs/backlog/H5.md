## Historia
Como usuario quiero añadir comentarios a una solicitud para dejar información de seguimiento.

## Criterios de aceptación (borrador)
- `POST /requests/{id}/comments` con `author` y `text` añade el comentario y devuelve 201.
- `GET /requests/{id}/comments` devuelve los comentarios en orden de creación.
- No se pueden añadir comentarios a una solicitud cerrada: devuelve 409.
- Si el id no existe, devuelve 404.
