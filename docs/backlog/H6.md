## Historia
Como equipo queremos que un modelo de IA revise nuestras especificaciones para detectar ambigüedades antes de programar.

## Criterios de aceptación (borrador)
- Una función `review_spec(spec_markdown)` envía la especificación a un modelo de Amazon Bedrock (API Converse, con `boto3`) y devuelve `{ "ambiguities": [...], "suggested_tests": [...] }`.
- El cliente de Bedrock se inyecta, para poder simularlo en los tests.
- Tests con respuestas simuladas para tres casos: respuesta correcta, error de permisos y respuesta incompleta.
- Los tests no hacen llamadas reales ni generan coste.

## Notas
- Llamada real solo cuando haya acceso a una cuenta AWS, con credenciales temporales.
- Ampliación opcional: exponer `review_spec` como herramienta MCP.
